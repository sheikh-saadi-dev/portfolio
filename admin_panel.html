How to get your GitHub Token

একটা Personal Access Token (classic) দরকার যেটা দিয়ে Admin Panel তোমার repo তে projects.json লিখতে পারবে।

1
GitHub.com → Profile → Settings
2
Left sidebar → Developer settings (একদম নিচে)
3
Personal access tokens → Tokens (classic)
4
Generate new token (classic) → Note: "Portfolio Admin" → Scope: repo ✓ → Generate
5
Token copy করো (একবারই দেখাবে!) → নিচে paste করো
